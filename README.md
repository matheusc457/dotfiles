## Dotfiles
My personal dotfiles for my Arch Linux setup.

This repository was created to store and preserve my dotfiles to use as a backup, feel free to use!

## What's here?
- Sway (Window Manager)
- i3 (Window Manager)
- Polybar (i3 status bar)
